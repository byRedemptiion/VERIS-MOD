# VERIS MOD

Utilitaire Windows pour personnaliser les sons de Discord — un son et un volume par événement, retour au son d'origine en un clic.

Par **byRedemptiion**.

## Télécharger

Dernière version : [Releases](../../releases/latest) → `VERIS_MOD_Setup_X.Y.Z.exe`

1. Double-clique sur le setup (aucun droit administrateur nécessaire).
2. Lance VERIS MOD depuis le raccourci du Bureau.
3. Accepte « Activer VERIS MOD » : Discord est fermé puis relancé automatiquement.

> Windows peut afficher SmartScreen (application non signée) : « Informations complémentaires » puis « Exécuter quand même ».

## Mises à jour

VERIS MOD vérifie les nouvelles versions au lancement et propose de les installer d'un clic.
Tes réglages, sons et profils (`%APPDATA%\Audely`) sont conservés.

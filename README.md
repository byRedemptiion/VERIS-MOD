# ViiCord

Utilitaire Windows pour personnaliser les sons de Discord — un son et un volume par événement, retour au son d'origine en un clic.

Par **byRedemptiion**.

## Télécharger

Dernière version : [Releases](../../releases/latest) → `ViiCord_Setup_X.Y.Z.exe`

1. Double-clique sur le setup (aucun droit administrateur nécessaire).
2. Lance ViiCord depuis le raccourci du Bureau.
3. Accepte « Activer ViiCord » : Discord est fermé puis relancé automatiquement.

> Windows peut afficher SmartScreen (application non signée) : « Informations complémentaires » puis « Exécuter quand même ».

## Mises à jour

ViiCord vérifie les nouvelles versions au lancement et propose de les installer d'un clic.
Tes réglages, sons et profils (`%APPDATA%\ViiCord`, migrés automatiquement depuis l'ancien dossier) sont conservés.
